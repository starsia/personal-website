## Problem

Students who just joined their university might not be sure of their degree choice. I wanted to a create a game that they can play to explore degree choices.

## My Role

I was the Software Engineer, responsible for:
- Building the game in Unity with C#
- Setting up authentication for players to save their progress
- Set up the story engine for path choices
- Bundle and deploy package to online game platforms
- Writing the stories, and implementing the programmatic flow using Ink

## Approach

- **Sprints:** Use weekly checkpoints to review my progress and achieve those goals.
- **User satisfaction:** Player's progress should be saved, hence the need for authentication features for returning players.
- **Test frequently:** Played it through myself, and also got others to play try it and find bugs.
- **Deployment:** Ensured the game was bundleable and easily playable on the web.

## Outcome

Check it out here: [Parallel uNivUSes](https://starsia.itch.io/parallel-univus)
It is a game that works well and can be played online!

## What I'd improve next

I would set up a CI/CD pipeline to immediately bundle the recent push to main onto the game platform.
