This site's current deployment pipeline is push-to-deploy on Vercel. It's convenient, but it hides most of the actual infrastructure work behind a dashboard. The next project is meant to expose that work so I can understand it deeply.

## The plan

A small standalone Spring Boot API containing one or two endpoints.

Containerize it with Docker, push to a registry, and deploy to a real host like Fly.io, Render, or an AWS free-tier box.

## Why this, why now

Terraform and VMware taught me infrastructure-as-code and virtualization from the ops side. This is the other half: building the application that gets deployed, not just the environment it runs in.

Will follow up here once there's something running.
