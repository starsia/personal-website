In August 2026, I've finished building the site you might be reading this on. It's build with a few tools:
- Next.js with the App Router
- Written in TypeScript and CSS is managed by Tailwind v4
- Blogs and essays are managed by MDX
- CI pipelines use GitHub Actions running lint/typecheck/tests on every PR before merge
- Deployed to Vercel

Currently, most of the real learning happened in getting the build to work correctly in the first place (Turbopack workspace-root resolution, class-based dark mode).

I do want to try out other deployment models that are more granular, so you can look out for a future Spring Boot project deployed on a VPS.
